# flabergast
flabergast - analyze and fix include path issues recursively within a project directory, in an automated fashion
---
HOW TO USE:
---
1: install python
2: `python flabergast.py` in the terminal from whatever project you'd like to fix's include path issues in's directory's root 
3: follow on screen instructions and manually fix ambiguous include paths by making selections 1 by 1 or if balling adding A for All
4: keep re running the script until the project compiles
5: done.

this for for c/cpp/c++
